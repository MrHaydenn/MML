# MML 0.8.0

- Replaced the wide sidebar with a compact icon rail, hover labels and scrollable instance shortcuts. Minecraft and Haydenn account controls remain separate.
- Updated the entire launcher to contrasting charcoal/grey surfaces, bright neutral icons and green highlights.
- Removed the large Discover heading so content tabs and search start at the top. Instance-specific browsing keeps a compact target label.
- Redesigned Skins with a large player preview, full-body saved-skin tiles, applied appearance markers and drag-and-drop PNG upload.
- Edit opens a centered dialog with its own 3D preview, texture replacement, wide/slim arm choices and owned-cape thumbnails. The existing pixel editor remains available inside an expandable section.
- Save keeps changes locally; Apply to Minecraft updates the skin and saved cape choice. Cancel discards draft changes. Existing saved skins remain compatible.

Updates download automatically on your selected channel. Click Restart to update when ready, or close and reopen MML. The Windows EXE is also available below.
