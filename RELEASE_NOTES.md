# MML 0.7.0

- Updates download in the background. Restart to update in the title bar installs silently and reopens MML; closing also installs downloaded updates. New installs use the current Windows user’s folder without an elevation option.
- Library opens by default, with consistent square tiles, Archive/Restore and custom instance icons in Settings.
- Linked pack updates are offered explicitly. Instance pages check for updates on open, on focus and every five minutes. A Versions tab supports switching installed pack versions, with compatibility confirmation for game/loader changes and additional content.
- Pack mods can be disabled while linked, including bundled JARs. Unchanged versions retain their disabled state; replacements may be enabled again. Additional content files stay unchanged during pack updates. Conflicts stop the update safely.
- Additional mods, resource packs and shaders offer compatible release updates separately.
- Skin editor adds a local library per Minecraft account, PNG upload, classic/slim arms, a 3D preview, and a simple pixel editor with undo/redo, eraser, eyedropper and grid.
- Apply uploads a saved skin to the actual Minecraft account. Select or hide capes owned by that account. Skin libraries stay local.

Download MML-Setup-0.7.0.exe or update from Settings. MML 0.6 and older will use their existing interactive update flow once; subsequent per-user updates use the new silent flow. Existing instances and accounts are retained. The first installer remains unsigned, and legacy all-users installations or Windows security policies can still require approval.
